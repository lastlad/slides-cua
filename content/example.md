# Why Computer Use Matters

## What it is
- Agents that operate software the way a person does
- They look at the screen, act, then look again
- No API integration required

## Why it is useful
- Works with any app that has a UI
- Reaches systems that never exposed an API
- Rides your existing logins and permissions

## What is still hard
- Slower than calling an API directly
- Sensitive to layout and timing changes
- Needs a verification step every turn

## Where it fits today
- Long tail internal tools
- One off migrations and backfills
- Demos and prototypes before an integration exists
